AI-Powered Phishing Detection

A browser extension + ML backend that identifies phishing websites in real time.

Protect users from phishing attacks — automatically

Monitor active tabs, analyze URLs with a trained model, and warn users before they reach malicious pages.

  • Real-time URL scanning
  • Machine learning (XGBoost / scikit-learn style)
  • Chrome extension with warning page
  • Lightweight, easy to run locally

Quick start

  1. Clone the repo: git clone https://github.com/Kumaresh-King/AI_Powered_Website_Phishing_Detection.git
  2. Run the backend: 
    cd backend
pip install -r requirements.txt
python api.py
  3. Load the extension in Chrome/Edge (Developer mode → Load unpacked → select extension/ folder)
  4. Open a suspicious URL to see the warning page in action

If you run the API locally, update extension/background.js to use http://localhost:5000/predict.

  • backend/ — Flask API that serves the ML model
  • model/ — feature extraction and model file

How it works

1. Capture

The extension listens for tab updates and captures the active URL.

2. Analyze

The backend extracts URL features (length, TLDs, keywords, special chars) and feeds them to the model.

3. Warn

If the model returns phishing, the extension redirects the user to a warning page allowing an override.
